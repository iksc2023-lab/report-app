# دفترچه یادداشت صوتی

اپلیکیشن اندرویدی فارسی برای تبدیل گفتار فارسی به متن و ذخیره یادداشت‌ها روی گوشی.

## امکانات
- تبدیل گفتار فارسی به متن با زبان fa-IR
- ورود و ویرایش دستی متن
- ذخیره، نمایش، ویرایش و حذف یادداشت‌ها
- ذخیره محلی یادداشت‌ها روی دستگاه

## ساخت APK
پس از هر بار push روی شاخه main، یا اجرای دستی Workflow با نام **Build Android APK**، فایل APK ساخته می‌شود.

برای دریافت فایل:
1. وارد زبانه Actions مخزن شوید.
2. آخرین اجرای موفق **Build Android APK** را باز کنید.
3. از بخش Artifacts فایل **DaftarcheYaddasht-APK** را دانلود کنید.
4. فایل ZIP را باز کرده و app-debug.apk را روی گوشی نصب کنید.

## نکته تشخیص گفتار
برای تبدیل گفتار، دسترسی میکروفون لازم است. تشخیص فارسی ممکن است به اینترنت و سرویس تشخیص گفتار نصب‌شده روی گوشی نیاز داشته باشد.
